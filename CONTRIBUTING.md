# Contributing to react-driller

genuinely thanks for being here <3

## Setup

```sh
bun install
bun test            # run the suite
bun run typecheck   # tsc --noEmit
bun run cli src/    # run the tool locally against a path
```

For a quick overview on how the analyzer actually works (the queue, the parent->child JSX flip), read [ARCHITECTURE.md](./ARCHITECTURE.md).
